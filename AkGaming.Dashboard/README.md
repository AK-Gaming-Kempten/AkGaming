# AkGaming.Dashboard

One-page internal shortcut dashboard for AK Gaming services and channels.

## Features

- Classical category board layout for shortcuts
- Custom preset supports creating categories
- Custom preset supports drag-and-drop moves between categories
- Presets: `vorstand`, `dev`, `eventleitung`, `all`, `custom`
- Local browser persistence for category visibility and custom category assignments
- Optional service reachability checks (manual refresh or opt-in auto checks) with status indicator

## Run

```bash
npm install
npm run dev
```
